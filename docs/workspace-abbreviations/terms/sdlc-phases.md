# SDLC-phases — SDLC phases A–F

Internal shorthand A–F for delivery phases; reader-facing names are Discover/Prioritize through Release.


## What it is

A Discover/Prioritize, B Specify, C Design, D Build, E Verify, F Release per SDLC.md ceremony map.

## When people say this

In bridge docs, WBS templates, and cross-maps — avoid leading with letters in user-facing copy.

## Where it lives

blueprints/sdlc/SDLC.md

## How it fits the ecosystem

Nested inside PDLC after P3. Not a seventh SDLC phase for ops — ops maps to P5/P6.

## Typical usage in plans and chat

Use SDLC-A style only in tables; prose should say Specify or Design per phase name.
