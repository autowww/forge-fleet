# DoD — Definition of Done

Exit criteria proving a work item or phase is complete — evidence-based, not narrative-only.


## What it is

Per-phase DoD in SDLC.md; spark-level DoD in forge-logs/. Distinct from Definition of Ready.

## When people say this

When closing Sparks, phase gates, or listing verifiable acceptance evidence in plans.

## Where it lives

blueprints/sdlc/SDLC.md; forge-logs/

## How it fits the ecosystem

PDCA loops in Cursor planning tie DoD to remediation re-runs until green.

## Typical usage in plans and chat

Plans should define acceptance evidence before implementation (forge-planning-standards.mdc).

## Do not confuse with

DoR
