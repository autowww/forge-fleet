Private Python library for governed synchronous LLM tasks, operators, and OpenAI-compatible transport.


## What it is

forge-lcdl/ under Code/ — pip install -e ../forge-lcdl. Tasks like seq, fallback_chain, until_ok.

When implementing governed LLM calls, LCDL handbook, or Cockpit↔LCDL boundary work.
