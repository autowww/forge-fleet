# LCDL-hub — LCDL workspace hub

Independent multi-repo folder ~/LCDL/ on the home directory — not forge-lcdl/ under Code/.


## What it is

Parent folder is not a git repository. Typical clones: forge-lenses, forge-composer.
Open LCDL.code-workspace.

## When people say this

When user says ~/LCDL, LCDL workspace, or wants clones outside Code/ hub.

## Where it lives

/home/lzvyahin/LCDL/

## How it fits the ecosystem

Distinct from lcdl library repo at Code/forge-lcdl/. No A11y-specific coupling.

## Typical usage in plans and chat

State full path when planning — LCDL hub vs lcdl repo is a frequent collision.

## Do not confuse with

lcdl
