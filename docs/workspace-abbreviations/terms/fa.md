# fa — forge-autodoc

Markdown → handbook HTML builder shipped inside ks at forge-autodoc/ — not a separate submodule.


## What it is

Python package forge_autodoc used by handbook generators. Source edits only in ks tree.

## When people say this

When changing handbook build pipelines, autodoc transforms, or running pytest forge-autodoc/tests.

## Where it lives

forgesdlc-kitchensink/forge-autodoc/

## How it fits the ecosystem

Consumed via kitchensink/forge-autodoc in bpw, ffw, flw, flsw, fpw, and other handbook shells.
