# fccw — forge-cockpit-web (alias)

Spoken/file alias for cockpit — same repo as forge-cockpit-web/.


## What it is

Abbreviation fccw = forge-cockpit-web. Use cockpit in workspace-map; fccw in long repo lists.

## When people say this

When distinguishing Cockpit web from forge-cockpit-mobile or forge-cockpit-memory in docs.

## Where it lives

forge-cockpit-web/

## How it fits the ecosystem

Cockpit family: fccw (web), fccm (mobile), fccmem (memory library).

## Typical usage in plans and chat

Prefer cockpit in Cursor rules; fccw when pairing with fccm/fccmem in tables.
