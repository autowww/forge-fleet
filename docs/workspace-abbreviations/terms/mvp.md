# MVP — Minimum Viable Product

Smallest product slice that tests core value hypothesis — a Product Spark category.


## What it is

Declared at Product Spark level with Assay Gate criteria for market-ready vs code-only release.

## When people say this

When committing to first external users or narrowing scope for P4 Launch readiness.

## Where it lives

blueprints/sdlc/methodologies/forge/planning/PLANNING-FLOW.md

## How it fits the ecosystem

MVP delivery still flows through SDLC phases once P3 commits to build.

## Typical usage in plans and chat

MVP plans should name Assay Gate evidence and which PDLC phase owns launch metrics.
