# hash — KS visual hash

Three-letter visual catalog id on emitted HTML — hash="Xyz" and data-ks-hash="Xyz" globally unique.


## What it is

Registered in docs/design/catalog/visual-registry.yaml; governed by ks-visual-catalog-remediation rules.

## When people say this

When changing KS components, design contracts, or proving deployment on public consumer HTML.

## Where it lives

forgesdlc-kitchensink/docs/design/catalog/

## How it fits the ecosystem

DET.HASH.REGISTRY_ROW crosswalks live DOM tokens against generated registry JSON.

## Typical usage in plans and chat

Visual changes update contract unless no_visual_change with evidence — both hash attributes required.

## Do not confuse with

git commit hash
